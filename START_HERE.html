From download to demo in three steps.

01

Extract the ZIP.

Right-click the downloaded ZIP and choose Extract All. Open the extracted folder. Do not run files from inside the ZIP preview.

02

Install once.

SETUP_WINDOWS.bat

Double-click this file. Use 64-bit Python 3.11–3.13. Internet is required only to install the Python packages.

03

Launch the mission.

START_WINDOWS.bat

Double-click and keep the terminal open. The browser opens after the engine becomes ready.

Open local app after startinghttp://127.0.0.1:8000

No Node server, Docker, map token or AI API key is needed to run the release. This is a local application, not a public hosted link. Stop it with Ctrl+C in the terminal. The supplied Windows launchers still need rehearsal on your laptop.

Demonstrate this first.

  1. Open the default Prydz Bay mission and click Run judge demo.
  2. Pause at the predicted iceberg crossing.
  3. Show the old corridor, computed alternative, lead time and explicit cost.
  4. Open Why this route?, then let a judge try a what-if input.

The full three-minute script and 20 judge answers are in the docs folder.

What really executes?

A trained random forest, Kalman state estimation, time-dependent route search, independent path checks, actual metric calculations, an interactive local map and a complete nine-stage demonstration.

The release passed 71 automated tests, 38 browser acceptance checks and 9 real HTTP checks. See TEST_REPORT.md for exact scope, methods and limitations.

Be precise with the judges.

The data is synthetic; the models and routing execute. No live polar feeds, field accuracy, real-vessel deployment or certified navigation safety are claimed. Public observation imports are overlays only. The default reroute costs extra fuel; the app shows that trade-off rather than forcing a savings claim.

If it does not start

Check that setup finished, that you extracted all files and that the terminal stays open. If port 8000 is occupied, open PowerShell in the project folder and run:

.\START_WINDOWS.bat --port 8001

Then visit http://127.0.0.1:8001. Detailed troubleshooting is in docs/quick-start.md. Do not disable security software to run this demo.
