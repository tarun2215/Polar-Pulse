# Third-party notices and reference use

## Natural Earth

The bundled `data/geography/antarctica.geojson` is derived from the Natural Earth low-resolution country geometry. Natural Earth states that its raster/vector map data is public domain. Attribution is provided for transparency even though the data's terms do not require it.

Reference: https://www.naturalearthdata.com/about/terms-of-use/

This is coarse reference geography, not a licensed marine navigation chart or a claim that the displayed coastline supports real route safety.

## NCPOR station reference

The Bharati coordinate reference is from the public NCPOR station information page. No NCPOR/MoES logo, endorsement, operational partnership, live feed or proprietary dataset is included or claimed.

Reference: https://ncpor.res.in/antarcticas/display/177-bharati

## Dependencies

Python packages are installed from the user's configured package index by `pip`; their source/binaries are not vendored into this archive. Their respective licenses and notices apply. Node/TypeScript is an optional development dependency only. The release includes no third-party font files; the UI uses system fonts. Icons and the POLAR PULSE symbol are simple project SVG markup.
